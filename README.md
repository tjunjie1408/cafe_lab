# Causal Cafe Lab

A hands-on causal machine learning workshop about deciding who should receive
a coupon under a fixed marketing budget.

## Branches

- `main`: participant entry point. Only this README is available here for now;
  the Colab notebook, observation dataset, and exercises will be added later.
- `instructor`: complete instructor workspace, including scripts, reference
  solutions, datasets, tests, and teaching guides.

Participant materials are being prepared. The instructor branch includes
answers and simulator truth; separate branches are not an access-control boundary.
